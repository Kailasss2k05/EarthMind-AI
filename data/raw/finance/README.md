# Finance / funding / cost reference documents go here

Drop PDF files directly in this folder.

## Where to get them
- World Bank / Green Climate Fund project financing reports:
  https://www.greenclimate.fund/documents
- National green bond or climate finance budget summaries
- Renewable energy cost benchmark reports (e.g. IRENA cost reports):
  https://www.irena.org/publications

## Suggested starting set
1. One climate finance / funding mechanism overview
2. One cost-benchmark report (useful later for the Finance Agent's ROI estimates)
