# Environmental / climate report documents go here

Drop PDF files directly in this folder.

## Where to get them
- IPCC reports (summary for policymakers PDFs): https://www.ipcc.ch/reports/
- UNEP (UN Environment Programme) reports: https://www.unep.org/resources
- Local/national environmental impact reports for your demo region

## Suggested starting set
1. One IPCC Summary for Policymakers (short, well-structured, great for testing chunking)
2. One environmental report relevant to your demo scenario
