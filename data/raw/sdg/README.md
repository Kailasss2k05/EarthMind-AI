# SDG documents go here

Drop PDF files directly in this folder (no sub-folders needed).

## Where to get them
- UN SDG official goal pages (each has a downloadable overview PDF): https://sdgs.un.org/goals
- UN SDG Progress Report (latest year): https://unstats.un.org/sdgs/report/
- Global Sustainable Development Report: https://sdgs.un.org/gsdr

## Suggested starting set (2-3 files is enough for Day 1)
1. The current year's SDG Progress Report (overview PDF)
2. One or two individual goal briefs relevant to your demo scenario
   (e.g. SDG 7 - Affordable & Clean Energy, SDG 13 - Climate Action)
